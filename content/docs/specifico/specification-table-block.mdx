The Specification Table block places Specifico data on a post or page directly from the WordPress block editor. Choose the current product's resolved specifications or select a saved table as the source.

## Add the block

1. Edit a post, page, product, or template in the block editor.
2. Open the block inserter and search for **Specification Table**.
3. Add the block where the table should appear.
4. Choose the table source in the block settings.

## Choose a source

The source determines which specifications the block renders.

### Current product

Use **Current product** when the block is displayed in a product context. Specifico uses the specifications resolved for that product, including its mapping rules and per-product data.

This option is useful in product content or templates where the product changes but the block layout stays the same.

### Specific table

Use **Specific table** to select one saved specification table. The selected table remains the source wherever the block appears, making this option suitable for regular posts, landing pages, and other content that is not tied to the current product.

## Block or shortcode?

Use the Specification Table block when you work in the block editor and want the source to be visible and editable in the page layout. Use the [`[specifico]` shortcode](/docs/specifico/shortcode) in classic-editor content, widgets, or integrations that accept shortcode text.

## Related release

The Specification Table block was added in Specifico 1.0.6. See the [Specifico changelog](/changelog/specifico) for the complete release notes.
