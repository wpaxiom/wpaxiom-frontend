The Comparison Table block displays two to four WooCommerce products side by side on any block-editor page. Select the products from the block settings and preview the shopper-facing comparison directly in the editor.

## Add a comparison table

1. Edit the page where the comparison should appear.
2. Open the block inserter and search for **Comparison Table**.
3. Add the block to the page.
4. Search for and select between two and four products.
5. Arrange the block in the page and publish your changes.

The block requires at least two products because a single product does not form a comparison. A maximum of four keeps the table usable across common page widths.

## Editor preview

The editor shows a live preview of the comparison table. Specifico uses the same renderer for the block preview, the frontend table, the comparison shortcode, and the shopper-facing comparison drawer.

Because these surfaces share a renderer, the table you review in the editor matches what visitors see after publishing.

## Which specifications appear?

Each selected product uses its resolved Specifico data. That includes the applicable mapped table and any per-product specification values, so the embedded comparison remains consistent with the product's own Specifications tab.

## Block, shortcode, or comparison drawer?

- Use the **Comparison Table block** when editors should select products visually and preview the result in the page layout.
- Use the comparison shortcode when the destination accepts shortcode text or product IDs are supplied programmatically.
- Use the comparison drawer when shoppers should choose products themselves while browsing the store.

See [Product comparison](/docs/specifico/product-comparison) for shopper controls, limits, and the complete comparison workflow.
