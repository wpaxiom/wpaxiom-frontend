Cartick is a WooCommerce enhancement plugin that adds cart features — sticky add-to-cart bars, off-canvas drawers, menu cart widgets, and button customisation — to any WooCommerce store.

## Requirements

- **WordPress 5.8** or newer
- **WooCommerce 6.3** or newer
- **PHP 7.4** or newer

<Callout type="tip">
  Not sure what version you're running? In WP admin go to **Tools → Site Health → Info** and expand the **Server** and **WordPress** sections.
</Callout>

## Manual upload

1. Download the Cartick ZIP supplied by wpaxiom. If you do not have a download, [contact support](/contact) to ask about availability.
2. Go to **Plugins → Add New Plugin → Upload Plugin**
3. Choose the `cartick.zip` file and click **Install Now**
4. Click **Activate Plugin**

## WP-CLI

```bash
wp plugin install ./cartick.zip --activate
```

## After activation

Open the new **Cartick** menu in the admin sidebar. You'll see a **Modules** page listing all available feature modules — all disabled by default. Continue to [Enabling and configuring modules](/docs/cartick/enabling-modules) to turn on the features you need.

<Callout type="warning">
  Cartick requires WooCommerce to be active. If WooCommerce is not installed, the Cartick admin page will show a dependency notice and no modules will load on the frontend.
</Callout>
