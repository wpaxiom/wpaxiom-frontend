The **Add to Cart Button** module lets you customise the label on WooCommerce's add-to-cart buttons per product type, and optionally apply a consistent colour and padding to every button on your store.

## Button text

Cartick lets you set separate labels for **shop/archive pages** and **single product pages**, for each of the four WooCommerce product types.

| Product type | Archive default | Single default |
|---|---|---|
| Simple | Add to cart | Add to cart |
| Variable | Select Options | Add to cart |
| Grouped | Select Options | Add to cart |
| External | Buy Now | Buy Now |

Edit any of these in the **Button Text** section of the module settings.

## Custom styling

Enable **Custom button style** to apply a uniform look to every add-to-cart button across your store — on shop pages, category pages, single product pages, and block-based product grids.

### Padding

Set independent top, right, bottom, and left padding values (in pixels, 0–200). Defaults to 15 px on all sides.

### Colours

Set a **Text colour** and a **Background colour**. The background colour also applies to the button border. Buttons get a subtle brightness change on hover and a slight lift on click.

<Callout type="tip">
  Custom styling uses `!important` to override typical theme rules. If your theme also uses `!important` on the same properties, raise the theme's specificity or add your own override rule with higher specificity.
</Callout>
