Cartick is built around independent **modules** — each one adds a specific cart feature and has its own settings. Modules are disabled by default; you pick the ones you want.

## Finding the modules page

Go to **Cartick** in the WP admin sidebar. The main screen lists all available modules with a toggle to enable or disable each one.

## Enabling a module

Click the toggle next to a module to switch it on. The page saves immediately — no save button required. Once enabled, the module begins working on the frontend straight away.

## Configuring a module

Each enabled module expands a settings panel beneath its toggle. Adjust the settings and they save automatically. Refer to the individual module docs for a full description of each setting:

- [Add to Cart Button](/docs/cartick/add-to-cart)
- [Sticky Cart](/docs/cartick/sticky-cart)
- [Menu Cart](/docs/cartick/menu-cart)
- [Off-Canvas Cart](/docs/cartick/off-canvas-cart)

## Disabling a module

Toggle the module off. Its settings are preserved, so re-enabling it restores the previous configuration.

<Callout type="info">
  Disabling a module removes all of its frontend output. No HTML is injected and no styles are loaded for disabled modules.
</Callout>
